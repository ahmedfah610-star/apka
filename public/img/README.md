# Zdjęcia strony głównej

Wrzuć tutaj pliki o **dokładnie tych nazwach** — strona podłączy je automatycznie
(a dopóki ich nie ma, używa zdjęć produktów jako zapasu):

| Plik                     | Gdzie się pojawia                | Zalecany kadr                          |
| ------------------------ | -------------------------------- | -------------------------------------- |
| `hero.jpg`               | Główne zdjęcie na górze (hero)   | poziomy, ~1600×900 px                   |
| `kat-dziewczynki.jpg`    | Kafel „Dziewczynki”              | pionowy/kwadrat, dziecko wyśrodkowane   |
| `kat-chlopcy.jpg`        | Kafel „Chłopcy”                  | pionowy/kwadrat, dziecko wyśrodkowane   |
| `kat-niemowleta.jpg`     | Kafel „Niemowlęta”               | pionowy/kwadrat, dziecko wyśrodkowane   |

Wskazówki:
- Przed wgraniem **przytnij prawy dolny róg** (znika wtedy znaczek/gwiazdka AI).
- Na `hero.jpg` przytnij górny pasek z ewentualnym napisem/logo — nagłówek dokłada strona.
- Kafle kadrują zdjęcie „na okładkę” (object-cover), więc najlepiej gdy dziecko jest na środku.
